Thread textures

Same chain-stitch geometry as the live seam, five ways of painting the thread. Sewn two thirds; below the live end there is no thread at all, only the needle holes (as you asked), and the loose tail. Left of each card is actual size on the linen; right is 4× at the point where sewn meets open.

T2 and T5 paint the thread with a diagonal two-ply twist; T3 roughens the edge with a little turbulence so it reads as cotton; T4 pushes the highlight for a polyester sheen. Hole style: the first three cards use the current soft dent, the last two a punched hole with a faint raised rim — tell me which hole you prefer independently of the thread.
